◉ What Are Neural Networks?

Neural networks represent a paradigm shift in computing. Unlike traditional programming where we explicitly tell computers what to do, neural networks learn from observational data, automatically discovering patterns and rules to solve problems.

"In a neural network we don't tell the computer how to solve our problem. Instead, it learns from observational data, figuring out its own solution."

This biologically-inspired approach enables computers to tackle problems that are extremely difficult to solve with conventional programming—like recognizing handwritten digits, understanding speech, or processing natural language.

◈ Why Deep Learning Matters

Until 2006, neural networks couldn't consistently outperform traditional approaches. The breakthrough came with the discovery of techniques for training deep neural networks—networks with many hidden layers that can learn increasingly abstract representations of data.

Today, deep learning achieves outstanding performance in computer vision, speech recognition, and natural language processing, and is deployed at massive scale by leading technology companies worldwide.

Perceptrons — Mathematical Foundation

Core Formula

$$\text{output} = \begin{cases} 0 & \text{if } \sum_j w_j x_j \leq \text{threshold} \\ 1 & \text{if } \sum_j w_j x_j > \text{threshold} \end{cases}$$

The perceptron computes a weighted sum of its inputs and applies a step function to produce a binary output.

Simplified Notation with Bias

$$\text{output} = \begin{cases} 0 & \text{if } w \cdot x + b \leq 0 \\ 1 & \text{if } w \cdot x + b > 0 \end{cases}$$

Where $b \equiv -\text{threshold}$ is called the bias. This measures how easy it is to get the perceptron to output 1.

$x_j$Input values (binary: 0 or 1) $w_j$Weights representing importance of each input $b$Bias term (negative threshold) $w \cdot x$Dot product: $\sum_j w_j x_j$
Example: Decision Making

Deciding whether to go to a festival based on three factors:

  • $x_1$ = Is the weather good? (weight $w_1 = 6$)
  • $x_2$ = Does your partner want to go? (weight $w_2 = 2$)
  • $x_3$ = Is it near public transit? (weight $w_3 = 2$)

With threshold = 5, if weather is good ($x_1=1$): $6(1) + 2(0) + 2(0) = 6 > 5$ → Go! ✓

Intuition

A perceptron is a simple decision-maker that weighs evidence. Large weights mean that input matters more. The bias controls how "trigger-happy" the neuron is—a large positive bias means it fires easily.

Sigmoid Neurons — Mathematical Foundation

The Sigmoid Function

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

The sigmoid function "squashes" any real number into the range (0, 1), providing a smooth, differentiable activation.

Neuron Output

$$a = \sigma(w \cdot x + b) = \frac{1}{1 + \exp(-\sum_j w_j x_j - b)}$$
$z$Weighted input: $z = w \cdot x + b$ $a$Activation (output) of the neuron $\sigma$Sigmoid activation function $e$Euler's number ≈ 2.71828

Key Derivative (Critical for Learning)

$$\sigma'(z) = \sigma(z)(1 - \sigma(z))$$

This elegant property makes the derivative easy to compute—it's just the output times one minus the output!

Why Sigmoid Matters

Small changes in weights produce small changes in output:

$$\Delta \text{output} \approx \sum_j \frac{\partial \text{output}}{\partial w_j} \Delta w_j + \frac{\partial \text{output}}{\partial b} \Delta b$$

This is crucial for learning! Unlike perceptrons where output jumps between 0 and 1, sigmoid allows gradual adjustments.

Intuition

Think of $z = w \cdot x + b$ as "evidence". When $z$ is large and positive → $\sigma(z) \approx 1$ (strong yes). When $z$ is large and negative → $\sigma(z) \approx 0$ (strong no). When $z \approx 0$ → $\sigma(z) \approx 0.5$ (uncertain).

Backpropagation — Mathematical Foundation

The Four Fundamental Equations

Backpropagation is built on four key equations that compute the error and gradients efficiently:

BP1: Error in Output Layer

$$\delta^L = \nabla_a C \odot \sigma'(z^L)$$

The error $\delta^L$ in the output layer combines how fast the cost changes with activation ($\nabla_a C$) and how fast the activation changes with weighted input ($\sigma'(z^L)$).

BP2: Error Propagation

$$\delta^l = ((w^{l+1})^T \delta^{l+1}) \odot \sigma'(z^l)$$

This propagates the error backward: the error in layer $l$ depends on the error in layer $l+1$, weighted by the connections between them.

BP3: Gradient for Biases

$$\frac{\partial C}{\partial b^l_j} = \delta^l_j$$

The gradient of cost with respect to bias equals the error—beautifully simple!

BP4: Gradient for Weights

$$\frac{\partial C}{\partial w^l_{jk}} = a^{l-1}_k \delta^l_j$$

The gradient for a weight is the product of the input activation and the output error.

$\delta^l$Error vector for layer $l$ $C$Cost (loss) function $\odot$Hadamard (element-wise) product $a^l$Activation vector for layer $l$ $z^l$Weighted input vector for layer $l$
Algorithm Steps
  • Forward pass: Compute $z^l$ and $a^l$ for all layers
  • Output error: Compute $\delta^L$ using BP1
  • Backpropagate: For $l = L-1, L-2, ..., 2$, compute $\delta^l$ using BP2
  • Compute gradients: Use BP3 and BP4 to get all $\frac{\partial C}{\partial w}$ and $\frac{\partial C}{\partial b}$
Intuition

Backpropagation answers: "How much did each weight contribute to the error?" It works backward from the output, attributing blame to each weight based on how much it influenced the final mistake. Weights that contributed more to the error get adjusted more.

Gradient Descent — Mathematical Foundation

Cost Function

$$C(w, b) = \frac{1}{2n} \sum_x \| y(x) - a^L(x) \|^2$$

The quadratic cost (MSE) measures the average squared difference between predictions $a^L$ and true labels $y$ across all training examples.

Update Rule

$$w \rightarrow w' = w - \eta \frac{\partial C}{\partial w}$$ $$b \rightarrow b' = b - \eta \frac{\partial C}{\partial b}$$
$\eta$Learning rate (step size) $\frac{\partial C}{\partial w}$Gradient of cost with respect to weight $n$Number of training examples

Stochastic Gradient Descent (SGD)

$$w \rightarrow w' = w - \frac{\eta}{m} \sum_{j=1}^{m} \frac{\partial C_{X_j}}{\partial w}$$

Instead of computing gradients over all training data, SGD uses random mini-batches of size $m$, dramatically speeding up learning.

Gradient as Direction of Steepest Descent

The change in cost when we move by $\Delta v$ in parameter space:

$$\Delta C \approx \nabla C \cdot \Delta v$$

To minimize cost, we choose: $\Delta v = -\eta \nabla C$

This gives us: $\Delta C \approx -\eta \|\nabla C\|^2 \leq 0$ (always decreasing!)

Mini-Batch SGD Algorithm
  • Shuffle training data randomly
  • Partition into mini-batches of size $m$
  • For each mini-batch, compute gradient using backprop
  • Update weights: $w \leftarrow w - \frac{\eta}{m} \sum \nabla C$
  • Repeat until convergence (one full pass = one epoch)
Intuition

Imagine rolling a ball down a hilly landscape where height = error. The gradient tells you which direction is steepest downhill. Taking steps opposite to the gradient moves you toward lower error. The learning rate controls step size—too large and you overshoot; too small and learning is slow.

Cross-Entropy Loss — Mathematical Foundation

The Problem with Quadratic Cost

With quadratic cost and sigmoid activation, the gradient contains $\sigma'(z)$:

$$\frac{\partial C}{\partial w} = (a - y) \sigma'(z) x$$

When the neuron saturates ($\sigma'(z) \approx 0$), learning becomes extremely slow even when the output is very wrong!

Cross-Entropy Cost Function

$$C = -\frac{1}{n} \sum_x \left[ y \ln a + (1-y) \ln(1-a) \right]$$
$n$Number of training examples $y$Desired output (0 or 1) $a$Actual output of the neuron $\ln$Natural logarithm

The Key Advantage

$$\frac{\partial C}{\partial w_j} = \frac{1}{n} \sum_x x_j (a - y)$$ $$\frac{\partial C}{\partial b} = \frac{1}{n} \sum_x (a - y)$$

The $\sigma'(z)$ term disappears! Learning speed is now controlled by the error $(a-y)$, not by how saturated the neuron is.

Softmax with Log-Likelihood

$$a^L_j = \frac{e^{z^L_j}}{\sum_k e^{z^L_k}}$$

For multi-class classification, softmax converts outputs to probabilities that sum to 1. Combined with log-likelihood cost:

$$C = -\ln a^L_y$$
Intuition

Cross-entropy measures the "surprise" when the true distribution $y$ is encoded using the predicted distribution $a$. When prediction matches reality, surprise (and cost) is low. When they differ greatly, surprise is high, driving faster learning.

Regularization — Mathematical Foundation

The Overfitting Problem

A network with many parameters can memorize training data instead of learning general patterns. The model fits noise rather than signal, performing poorly on new data.

L2 Regularization (Weight Decay)

$$C = C_0 + \frac{\lambda}{2n} \sum_w w^2$$
$C_0$Original unregularized cost function $\lambda$Regularization parameter (controls strength) $n$Size of training set $\sum_w w^2$Sum of squared weights

The weight update rule becomes:

$$w \rightarrow w\left(1 - \frac{\eta \lambda}{n}\right) - \eta \frac{\partial C_0}{\partial w}$$

Weights decay by factor $(1 - \frac{\eta \lambda}{n})$ each update, preventing them from growing too large.

L1 Regularization

$$C = C_0 + \frac{\lambda}{n} \sum_w |w|}$$

The weight update becomes:

$$w \rightarrow w - \frac{\eta \lambda}{n} \text{sgn}(w) - \eta \frac{\partial C_0}{\partial w}$$

L1 tends to concentrate weights in a smaller number of high-importance connections, creating sparse networks.

Dropout

During training, randomly "drop" neurons with probability $p$:

$$\tilde{a}^l = \frac{1}{1-p} \cdot r^l \odot a^l$$

where $r^l$ is a vector of Bernoulli random variables with $P(r^l_j = 1) = 1-p$

At test time, use all neurons but scale weights by $(1-p)$ to maintain expected values.

Comparing L1 vs L2
  • L2: Penalizes large weights quadratically → weights shrink proportionally → dense, small weights
  • L1: Penalizes large weights linearly → constant shrinkage → sparse weights (many zeros)
  • Dropout: Ensemble effect → forces redundancy → robust features
Intuition

Regularization embodies Occam's Razor: simpler models generalize better. By penalizing complexity (large weights), we force the network to find solutions that capture true patterns rather than memorizing noise. Dropout can be seen as training an ensemble of networks that share weights.

Vanishing Gradients — Mathematical Foundation

The Problem in Deep Networks

In networks with many layers, gradients in early layers become exponentially smaller than gradients in later layers, causing early layers to learn extremely slowly.

Gradient Flow Through Layers

For a deep network, the gradient in layer $l$ involves a product:

$$\frac{\partial C}{\partial b^l} = \sigma'(z^l) \cdot w^{l+1} \cdot \sigma'(z^{l+1}) \cdot w^{l+2} \cdots \sigma'(z^L) \cdot \frac{\partial C}{\partial a^L}$$

This is a product of many terms $w^j \sigma'(z^j)$.

Why Gradients Vanish

$$\sigma'(z) = \sigma(z)(1 - \sigma(z)) \leq \frac{1}{4}$$

The sigmoid derivative is at most 0.25! With standard initialization, $|w| < 1$ typically, so:

$$|w \sigma'(z)| < \frac{1}{4}$$

Each layer multiplies the gradient by a factor less than 1/4. After $n$ layers:

$$|\text{gradient}| \propto \left(\frac{1}{4}\right)^n \rightarrow 0$$

Exploding Gradients

If $|w \sigma'(z)| > 1$, the opposite occurs:

$$|\text{gradient}| \propto k^n \rightarrow \infty \quad \text{for } k > 1$$

Gradients explode, causing unstable training with wild weight oscillations.

Solutions

ReLU Activation:

$$\text{ReLU}(z) = \max(0, z), \quad \text{ReLU}'(z) = \begin{cases} 1 & z > 0 \\ 0 & z \leq 0 \end{cases}$$

Gradient is 1 for positive inputs—no vanishing!

He Initialization:

$$w \sim \mathcal{N}\left(0, \sqrt{\frac{2}{n_{in}}}\right)$$

Scales initial weights based on number of inputs to maintain variance across layers.

Intuition

Think of gradients as a signal flowing backward through the network. Each layer is like a leaky pipe—sigmoid activation loses at least 75% of the signal at each layer. After many layers, almost no signal reaches the early layers. ReLU acts like a pipe with no leakage (for positive values), allowing gradients to flow freely.

Convolutional Networks — Mathematical Foundation

Local Receptive Fields

Instead of connecting every input to every neuron, each neuron connects only to a small local region of the input:

$$a^1_{j,k} = \sigma\left( b + \sum_{l=0}^{f-1} \sum_{m=0}^{f-1} w_{l,m} \cdot a^0_{j+l, k+m} \right)$$
$f$Filter (kernel) size (e.g., 3×3, 5×5) $w_{l,m}$Shared weights in the filter $a^0_{j,k}$Input at position $(j,k)$ $a^1_{j,k}$Output feature map at position $(j,k)$

Convolution Operation

$$(I * K)_{i,j} = \sum_{m} \sum_{n} I_{i+m, j+n} \cdot K_{m,n}$$

The kernel $K$ slides across input $I$, computing dot products at each position to produce the feature map.

Output Dimensions

$$\text{output size} = \frac{n - f + 2p}{s} + 1$$
$n$Input size $f$Filter size $p$Padding (zeros added around input) $s$Stride (step size of filter movement)

Pooling Layers

Max Pooling:

$$a^{pool}_{j,k} = \max_{0 \leq l,m < p} a^{conv}_{j \cdot s + l, k \cdot s + m}$$

Takes the maximum value in each pooling region, providing translation invariance and dimensionality reduction.

Parameter Efficiency

Fully connected: For 28×28 input to 100 neurons:

$$\text{parameters} = 28 \times 28 \times 100 = 78,400$$

Convolutional: For 5×5 filter with 20 feature maps:

$$\text{parameters} = 5 \times 5 \times 20 = 500$$

~150× fewer parameters through weight sharing!

Typical CNN Architecture
  • Input: Raw image (e.g., 28×28×1 for MNIST)
  • Conv + ReLU: Extract local features with $k$ filters
  • Pooling: Reduce spatial dimensions, gain invariance
  • Repeat: Stack more Conv/Pool layers for hierarchical features
  • Flatten + FC: Dense layers for final classification
Intuition

CNNs exploit two key insights: (1) Local patterns matter—edges, textures exist in small regions; (2) Patterns are translation-invariant—an edge is an edge regardless of position. Weight sharing means learning one edge detector that works everywhere. Deeper layers combine local features into increasingly abstract concepts: edges → shapes → parts → objects.

◆ Why Fundamentals Matter

While modern libraries make it easy to build neural networks quickly, understanding the underlying principles provides lasting insights that remain relevant as technologies evolve.

"Technologies come and technologies go, but insight is forever. We'll learn the core principles behind neural networks and deep learning by attacking concrete problems."

A deep understanding of concepts like backpropagation helps you become not just a user of deep learning tools, but someone capable of understanding why things work, diagnosing problems, and innovating new algorithms.
